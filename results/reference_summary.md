## Overlaps

Rule: Later file wins: for each second, take the value from the highest-numbered file (V > IV > III > II > I) that has a valid value there. An earlier file only fills seconds the later files lack. Within one file, the first row for a second wins. Reason: in every overlap the two files hold the same or nearly the same values with their time labels shifted by about one to five minutes, and the 15-minute block-clock check (scripts/check_time_axis.py) finds labels drifting late over the length of each file. The later file is near its own start there, so its labels have drifted less.
